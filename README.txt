PHARMACEUTICS QUIZ WHEEL V3

1. Extract the entire ZIP file (do not run HTML inside the ZIP).
2. Open index.html in Chrome or Edge. Keep assets folder beside index.html.
3. Click the center of the wheel or any wheel segment to spin.
4. Choose an answer on screen; the app grades it automatically using the provided answer key.
5. Use the sound test button to verify audio. Check browser volume and tab mute if needed.
6. Reset the round in settings to start fresh.
7. Full student names and question links are shown in settings; shortened names are used on the wheel for readability.

No internet required. Audio files are bundled in assets.
